# 교실 수업 알리미

초등 교실 전자칠판용 웹앱입니다. 수업종 알리미 + 오늘 시간표 + 아침활동 안내판 +
알림장(학생별 할일 · 1인1역) + 타이머 + 하이클래스용 복사 기능이 한 화면에 있습니다.
프레임워크 없이 순수 HTML/CSS/JS로 되어 있고, 기기 간 실시간 동기화는 Firebase
Firestore를 씁니다.

## 처음 쓰기 전에 해야 할 설정 (체크리스트)

1. **Firebase 프로젝트 만들기 + Firestore 켜기**
   Firebase 콘솔에서 프로젝트를 만들고 Firestore Database를 활성화합니다.
   그다음 `js/firebase-config.js`의 `REPLACE_ME` 6개 값(apiKey, authDomain,
   projectId, storageBucket, messagingSenderId, appId)을 실제 값으로 바꿉니다.
   값은 **Firebase 콘솔 > 프로젝트 설정 > 일반 > 내 앱(웹)** 에 있습니다.
   교체 전에는 동기화가 전혀 동작하지 않습니다.

2. **Firestore 보안 규칙 붙여넣기**
   `firestore.rules` 내용을 **Firebase 콘솔 > Firestore Database > 규칙** 탭에
   직접 붙여넣고 게시합니다. 이 저장소에서 자동으로 배포되지 않습니다.
   ⚠️ 이 규칙은 누구나 읽고 쓸 수 있게 열려 있고, `js/main.js`의 `EDIT_PIN`도
   소스코드에 평문으로 들어 있습니다. 즉 **주소를 아는 사람은 누구나 내용을 읽고
   고칠 수 있습니다** — 학생 이름·할일 정도의 낮은 민감도 데이터라는 전제에서
   의도적으로 택한 절충입니다. 더 강한 보호가 필요하면 Firebase Auth를 도입하세요.

3. **편집 PIN 바꾸기**
   `js/main.js`의 `const EDIT_PIN = '1234';`를 원하는 4자리 PIN으로 바꿉니다.

4. **시간표 확인**
   초기 시간표는 `js/seed-data.js`의 `INITIAL_SCHEDULE`에 들어 있습니다.
   실제 시간표와 대조해 보고, 다른 곳이 있으면 앱에서 **✏️ 편집**(PIN 입력) 후
   오른쪽 시간표 편집 폼에서 요일·교시별로 고치면 됩니다.
   교시를 없애려면 과목에서 **비우기(교시 삭제)** 를 고르고 적용합니다.

5. **학생 명단 입력**
   **📥 엑셀로 학생 명단 가져오기**(번호·이름 두 열의 xlsx)로 한 번에 넣거나,
   편집모드의 **+ 학생 추가**로 한 명씩 넣습니다. 1인1역은 편집모드에서 학생 줄의
   1인1역 칸에 직접 입력합니다.

6. **편집모드 잠그기**
   편집이 끝나면 **✏️ 편집** 버튼을 다시 눌러 잠급니다(잠글 때는 PIN을 묻지 않음).
   교실 공용 태블릿은 하루 종일 켜져 있으므로 편집이 끝나면 꼭 잠가주세요.
